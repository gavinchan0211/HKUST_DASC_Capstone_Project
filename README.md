# HKUST_DASC_Capstone_Project (Data collection part)

Capstone project for my graduation.
The main idea in this project is we need to find a dataset online on any field (I found a dataset about sleeping vs productivity on Kaggle). And then, we need to make a program that is able to replicate the dataset we have found (of course the numbers and data inputs doesn't need to be the same, only the columns, and type of data collected needs to be consistant).
We will then use the data collected to make graphs for insights in Power BI, and present the findings with a powerpoint and a video guide, but I haven't put them here yet.
